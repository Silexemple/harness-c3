λ Harness C3

USB companion display for the Harness daemon — ESP32-C3-MINI-1U + GC9A01 240×240 round panel.

Your browser does not support WebSerial — use Chrome or Edge (on HTTPS or localhost). This page needs HTTPS or localhost to access the serial port.

Plug the device in with a data-capable USB-C cable, click the button, pick the USB JTAG/serial debug unit port.

Browser requirements: Chrome, Edge or Opera (WebSerial API). The page must be served over HTTPS or localhost. Firefox and Safari cannot flash from the browser — use the manual method below.

Wiring (default pin map)

BTN_A7short = next, long = confirm
BTN_B8back / cancel — do not hold at boot
Buzzer (optionnel)1-1 in menuconfig disables it

USB is the ESP32-C3's native port (GPIO18 = D−, GPIO19 = D+). All pins are overridable under menuconfig → Harness C3 Configuration.

Manual flashing

With esptool, using the merged image from the Releases page:

esptool.py --chip esp32c3 write_flash 0x0 harness-c3-merged.bin

Or from source with ESP-IDF v5.5:

git clone https://github.com/Silexemple/harness-c3.git
cd harness-c3/firmware
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor

After flashing

Plug the dial into the computer running the Harness daemon. The screen shows “Plug into a Harness daemon” until the daemon answers the device’s hello, then the agent carousel appears.

Firmware version shown on the boot screen and reported to the daemon is read from the running image — this page always flashes the latest CI build of main.
